# astrbot_plugin_rock_merchant_notify

一款为 [AstrBot](https://github.com/Soulter/AstrBot) 开发的洛克王国远行商人商品监控与通知插件。

本插件移植自 [sslna/rock-merchant-notify](https://github.com/sslna/rock-merchant-notify)。将原版基于 GitHub Actions 的定时任务工作流，重构适配为 AstrBot 的异步插件架构。**v1.3.0 版本**全面升级了数据校验机制，采用**连续两次比对验证**策略，有效防止网络波动导致的误报，同时支持分群/私聊独立订阅、灵活推送模式、艾特规则配置及实时指令查询。

---

## ✨ 功能特性

* **二次数据验证**：连续抓取两次数据，比对一致后才推送通知，最大限度避免网络波动引起的误报。
* **智能次数熔断**：最多连续抓取 5 次进行数据比对，防止无限循环抓取。
* **原生订阅推送**：无需依赖外部服务，支持在群聊或私聊中直接订阅商人刷新自动推送。
* **分群独立配置**：每个订阅窗口均可独立设置推送模式（全部推送/仅匹配关注商品推送/静默）及是否 `@全员`。
* **后台异步轮询**：每 2 分钟自动检查一次，采用异步线程执行网络请求，绝不阻塞机器人主进程。
* **增量变更通知**：自动比对商品数据，仅在商品数据真实发生改变时触发推送，拒绝消息刷屏。
* **关键词高亮关注**：支持设置重点关注商品，命中后通知将高亮提示，方便快捷捡漏。
* **轻量持久化存储**：严格遵守 AstrBot 数据规范，历史数据自动滚动清理（最多仅保留最新的 20 组抓取记录），防止存储文件无限膨胀。
* **可视化配置**：完美支持 AstrBot 管理面板，核心轮询参数均可在 Web 页面直接修改。

## 🛠️ 安装方法

### 1. 通过管理面板安装 (推荐)
打开 AstrBot Web 管理面板，点击 **安装插件** 并切换到 **从链接安装**：

1. 在"输入插件仓库链接"输入框中粘贴本插件的 GitHub 地址：
```text
   https://github.com/Zzzzzzouhang/astrbot_plugin_rock_merchant_notify
   ```
2. 根据你的网络状况选择是否开启 **GitHub 加速**。
3. 点击 **安装**，等待面板提示下载完成。

### 2. 手动安装 (备选)
如果你无法通过面板联网安装，也可以手动将本仓库克隆到你 AstrBot 运行目录的 `data/plugins/` 下：
```bash
cd data/plugins/
git clone https://github.com/Zzzzzzouhang/astrbot_plugin_rock_merchant_notify.git
```

### 3. 安装依赖
解析网页需要用到特定的 Python 依赖库，请确保在运行 AstrBot 的环境中安装它们：
```bash
pip install requests beautifulsoup4 tzdata
```

## ⚙️ 配置说明

在 AstrBot 管理面板的插件设置中，你可以对以下核心参数进行自定义配置（或直接修改 `_conf_schema.json`）：

| 配置项 | 类型 | 默认值 | 说明 |
| :--- | :--- | :--- | :--- |
| `merchant_url` | string | `https://www.onebiji.com/...` | 远行商人页面的抓取源地址 |
| `refresh_times` | string | `08:01,12:01,16:01,20:01` | 每天规律刷新的时间点 (使用逗号分隔) |
| `refresh_window_minutes`| int | `60` | 刷新窗口期(分钟)，仅在该窗口时间内才会触发实际抓取 |
| `watch_items` | string | `国王球,棱镜球,炫彩精灵蛋,祝福吊坠` | 重点关注商品名称 (逗号分隔，命中时可触发特定规则推送) |

## 🎮 使用方法 (机器人指令)

在任意群聊或私聊窗口中向机器人发送以下指令即可完成交互：

### 📌 基础查询与订阅
* **`/远行商人`**
  手动触发即时抓取，无需等待定时任务，机器人会立刻将当前商人的最新商品列表回复在窗口中。
* **`/订阅商人`** 🔒
  将当前窗口加入后台自动推送列表。当系统检测到商人刷新时，会自动下发通知。（默认规则：只匹配到关注商品时推送，不@全员）。**仅群管理员/群主可用，私聊无限制。**
* **`/取消订阅商人`** 🔒
  取消当前窗口的自动推送。**仅群管理员/群主可用，私聊无限制。**
* **`/商人历史`**
  查看远行商人的历史刷新记录。输出格式：`[检查时间] [物品, 物品, 物品]`，最多返回最近 15 条数据。持久化最多保存 1000 条历史记录。

> 💡 所有指令的回复末尾都会自动追加一行常用指令提示：`/远行商人 /「取消」订阅商人  /商人历史`，方便快速切换。🔒 标记的指令在群聊中仅管理员/群主可使用，私聊不受限制。

### ⚙️ 高级分群设置 (需先订阅) 🔒
* **`/设置商人推送 [参数]`** 🔒
  自定义当前窗口的推送触发条件。**仅群管理员/群主可用，私聊无限制。** 支持的参数：
  * `0` -> **全部推送** (只要商人刷新，无论出什么商品都推送)
  * `1` -> **只匹配到商品推送** (只有刷出了 `watch_items` 中的关注商品才推送)
  * `2` -> **完全不推送** (暂时静默)
* **`/设置商人艾特 [参数]`** 🔒
  自定义触发推送时是否提醒全员。**仅群管理员/群主可用，私聊无限制。** 支持的参数：
  * `0` -> **不@全员** (仅发送普通消息)
  * `1` -> **@全员** (强提醒，需机器人拥有对应群权限)

## 🔄 抓取策略说明

本插件采用**连续两次数据比对验证**的智能抓取策略：

1. **第 1 次抓取**：获取当前商品数据并缓存，等待下一次比对。
2. **第 2 次抓取**：与第 1 次结果进行比对。
   - **结果一致**：立即推送通知，本时间窗口不再继续抓取。
   - **结果不一致**：更新缓存，继续下一次抓取比对。
3. **第 3~4 次抓取**：重复第 2 步逻辑，直到连续两次结果一致。
4. **第 5 次（熔断）**：达到最大抓取次数限制，使用最后一次结果推送并停止。

此策略有效防止了因网络延迟或页面加载不完整导致的误报推送。

## 📁 存储结构说明

插件的数据会规范化存储在 `data/plugin_data/astrbot_plugin_rock_merchant_notify/` 目录下：
* `latest.json`: 保存最新一次抓取到的商人状态，用于增量比对。
* `history.jsonl`: 抓取历史记录追溯（自动维护，最大上限 1000 条）。
* `subscribers.json`: 存储各个聊天窗口的订阅状态和分群配置。
